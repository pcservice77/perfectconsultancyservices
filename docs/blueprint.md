# **App Name**: Consultant Connect

## Core Features:

- Service Showcase: Display a curated list of consultancy services with descriptions and CTAs.
- Job Listings: Display available job opportunities with key details and an application link.
- Contact Form: Provide a simple form for users to submit inquiries or service requests.
- Tax Update Feed: Dynamically generate and display GST and Income-Tax updates via CMS.
- Subscription Service: Allow users to subscribe to a newsletter for the latest updates and job postings.
- AI Tax Update Summarizer: Provide summaries of the Tax Update Feed articles with a summarization tool. This tool highlights the key implications and deadlines.

## Style Guidelines:

- Primary color: Dark blue (#34495E) to convey professionalism and trust.
- Background color: Light gray (#F4F6F6), nearly white, for a clean and modern look.
- Accent color: Soft green (#2ECC71) to highlight key CTAs and important information.
- Body and headline font: 'Inter', sans-serif, for a modern and readable appearance.
- Note: currently only Google Fonts are supported.
- Use a set of professional and consistent icons to represent different services and sections.
- Maintain a clean and well-structured layout to ensure easy navigation and readability.
